Java Sorting Practice

This repository contains Java practice projects focused on sorting objects using Comparable and Comparator.

Projects

1. GameStoreSystem

A simple game store example that sorts games by their ratings in descending order.

Topics covered:

* Comparable
* Comparator
* compareTo()
* comparingInt()
* reversed()
* ArrayList
* Lambda expressions

2. StudentSortingSystem

A student sorting example that sorts students by their grades in ascending order.

Topics covered:

* Comparable
* compareTo()
* Collections.sort()
* Integer.compare()
* ArrayList

Technologies

* Java
* Collections Framework
* Object Sorting
